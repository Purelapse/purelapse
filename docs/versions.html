Version history

What has changed.

The key changes of every version at a glance. Every detail is in the full changelog (German).

Current

2.42.1-beta

20 November 2026
Download AppImageRelease on GitHub

Bug-fix release for 2.42.0. Anyone using 16-bit intermediate images should upgrade.

New

  • The selected engine is now always shown below the folder path – with a warning if its program is missing. A click opens the settings.

Fixed

  • 16-bit intermediate images combined with the telemetry overlay aborted while rendering the video. Frames already developed are kept – starting pass 2 again only renders the video.
  • Astro clean with 16-bit intermediate images no longer replaces nearly every pixel.
  • Hints about clipped highlights, the darktable engine and parallel processes updated to match 2.42.

Website

  • New “Technical reference” section with every feature in detail.
  • This version page.

2.42.0-beta

20 November 2026
Release on GitHub

The biggest overhaul so far: more accurate measurement, darktable on a par with ART and RawTherapee, cleaner videos. Includes the unpublished interim versions 2.40 and 2.41.

When upgrading: the measurement has changed – run pass 1 and pass 2 again for ongoing projects. Old settings files are migrated on first start.

Image quality

  • The sun and clipped highlights no longer distort the measurement. Residual flicker with the sun in frame: from up to 0.05 EV down to 0.0005 EV.
  • Recalibration judges clipped areas across the whole sequence and no longer creates flicker where there was none.
  • Camera move accurate to fractions of a pixel, without judder, with gentle acceleration and braking.
  • Video colours to the HD standard BT.709 and more thorough encoder settings.
  • New: HEVC 10 bit (CPU and NVIDIA) and 16-bit intermediate images against banding in the sky.

darktable

  • Keyframes carry the complete module stack – more than 60 modules from white balance to filmic are blended smoothly.
  • Quick settings (brightness, contrast, saturation, sharpening) with a real preview.
  • darktable-cli develops with up to four processes at once, even while darktable is open.
  • Hot-pixel correction now works, and the deflicker value reliably ends up in the effective exposure.

Usability

  • Icons instead of text for folder, refresh, reset and settings; clearer step buttons.
  • The log is now fully available in English as well.
  • Just one configuration file instead of up to 16 separate files in the home folder.

Reliability

  • All files are written atomically; write errors stop the run with a message.
  • darktable-cli can no longer hang: time limit per frame, immediate cancel.
  • No more ghost text with motion blur and telemetry overlay.
  • About 3000 automated checks run on every change.

2.39.0-beta

18 November 2026
Release on GitHub

First public beta.

Included

  • RAW deflicker with ART, RawTherapee and darktable in two passes, recalibration down to below 0.008 EV residual flicker.
  • Deflicker for JPG sequences in a single pass.
  • Keyframes with smooth blending and quick settings with a real preview from the engine.
  • Quick preview, start and end frame, measuring area, 16:9 camera move, motion blur, stabilisation, astro clean, telemetry.
  • Video output up to 8K: H.264/H.265 on CPU, NVIDIA, Intel QuickSync and VAAPI plus ProRes, with codec self-test.
  • Warnings for gaps, clipped and pink highlights; queue, Telegram, German and English.
